## 实际架构

MkDocs Material + Markdown；原生 JavaScript 增强。公共数据通过 auth-manager → knowledge-store → Supabase 读取；统一 safeHref/sanitizeBodyHtml 与 media-policy 管理链接、正文和媒体。条目有查询参数入口与 Python 构建的独立静态 SEO 页面。地图用 Leaflet；时间轴已有三个空间泳道；关系图为原生 SVG。部署由 GitHub Pages 工作流生成条目再严格构建。

全部 27 个业务/第三方脚本及 21 个样式全站加载。首页有重复导航、整屏 Hero、无搜索；动态地图默认世界视角。搜索仅前 12 条，且 searchEntries 未排除零分匹配，导致无结果状态失真。时间轴两套弹窗同时绑定；研究用语进入普通界面。静态条目具有 canonical、OG 与结构化数据，需要同步改进模板。

## 回归风险

1. 页面资源拆分需保持脚本依赖顺序，并覆盖独立静态条目、管理员页面、七主题与图库。
2. 不改 slug、数据库结构、数据关联、公开来源过滤规则和媒体授权记录。保持项目子路径。
3. 静态 SEO 页面与动态条目必须一致；网络失败不得擦除已生成正文。
4. 搜索修复零分结果会改变计数；分页需要真实 offset，不能只改界面按钮。
5. 弹窗统一需保证单次打开、焦点回到触发点、Esc 清理事件及滚动锁。
6. 老样式存在强覆盖与深色硬编码；通过局部 tokens 与覆盖层收敛。
7. 全量 JS 类型检查已有 785 个错误，记录基线，不将其伪装为通过。
