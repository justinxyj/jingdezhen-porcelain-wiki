## 编辑决定

- 以馆藏对象记录支持器物身份，以实际读到的论文论证支持技术与年代判断；百科用作入口，不整段替换专业来源。
- 新增人物稿去除空泛赞誉，将机构履历、个人回忆、参观转述与文学想象分别说明。“马基利”原文身份未明，不由中文音译补写英文传记。
- 一元配方不限定为单一矿点；钧窑不再笼统写作北宋官钧，按器皿类、陈设类及研究分歧叙述。
- 当前稿件已自行作出编辑审定；待办是剩余内容核验及实际发布能力，不是要求用户承担逐篇专业审核。

## 发布条件

1. 首先审查论断与出处是否对应。通用机构介绍不能证明一件器物的尺寸、年代或身份；工序稿中的通用技术解释也不等同于官方逐项定义。
2. 保留对象标识、中文元数据、英日字段、关系和媒体。新文案不自动改变条目类别、年代表或地理坐标。
3. 发布前重新读取线上记录，对照版本、时间戳和哈希；若基线变化，先合并最新编辑。
4. 使用既有馆长编辑与历史版本保存流程。其当前正文保存逻辑不更新 `sources`；上线前还需确保新出处与正文同步保存，不能只复制正文而保留旧的无关链接。
5. 时间轴渲染优先读取 `official_summary`。编辑综合稿发布时需明确旧字段处理，防止新稿保存后仍显示过期摘要；也不能把综合稿重新标成官方原文。
6. 当前环境只有公开读取配置，没有经过认证的馆长写入凭据。本轮未执行线上数据库更新，也未部署站点。
