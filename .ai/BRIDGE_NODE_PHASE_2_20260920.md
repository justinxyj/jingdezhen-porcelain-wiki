# Bridge Node Phase 2：15 节点深度证据审查

更新时间：2026-09-20

## 目标

本阶段不以“还能连谁”为目标，而只回答：

> 这个节点缺哪一条有独立证据、能够真正缩短两个知识/文明子网络结构距离的关键桥？

本轮在 273 条 A/A+/B evidence-grade 边、161 个节点的当前图上进行 Claim-by-Claim 审查。新增 10 条结构性 A 边，并对 3 条已有边完成 A 级证据升级。

原则仍为：

Entry → Relation Claim → Evidence → Source → Evidence Type → Boundary → Evidence Grade

多跳路径用于发现结构机会，不把多跳路径本身当成单条历史事实。

## 本阶段真正形成的结构性短链

朝鲜半岛 → 有田 → 日本出口瓷 → VOC → 欧洲

- Met：韩国陶工参与日本早期瓷业形成，并在Hizen/Arita建立生产基础。
- Met：日本出口瓷经长崎、荷兰贸易进入欧洲。
- Met：VOC标记的Arita瓷器。

景德镇青花 → 克拉克瓷 → 有田/日本出口瓷 → 欧洲

这里不把“技术完全移植”写进边，只记录可观察的模型、市场和再生产证据。Met明确记载Kraak成为日本出口瓷的模型，并有欧洲复制链；BM也记录日本Arita的Kraak风格出口瓷。 citeturn8search1turn3search4turn3search24

## 本阶段明确没有做的事

1. 没有因为“文明相近”制造边。
2. 没有把UNESCO/r23当成万能证据跳板。
3. 没有把二元配方直接写成“Meissen技术来源”。
4. 没有把朝鲜陶工参与日本瓷业扩大成“日本瓷器全部源于朝鲜”。
5. 没有把Kraak、日本出口瓷、Delft、Meissen之间的多跳路径写成单一历史事实。
6. 没有因为Brandes BC较低就否定Arita、Kraak、VOC的桥梁价值。
7. 没有为了降低孤立数量而继续制造低价值关系。

## Phase 2 的阶段结论

这一轮最重要的变化不是 entry_relations 从 263 条增加到 273 条。

真正的变化是：

> 图开始从“景德镇向外发散”转变成“文明之间存在可验证的往返反馈”。

目前已经可以用证据支持的核心结构来描述为：

景德镇 → 东亚 → 东南亚 → 伊斯兰世界 → 欧洲 → 日本 → 欧洲再生产

但必须注意：这是一组由多条独立证据边组成的网络结构，不是“一条历史路线”。

其中最关键的三个反馈回路是：

- 青花 → Kraak → 有田/日本出口 → 欧洲
- 青花 → 伊斯兰世界 → Iznik
- 外销瓷 → 东南亚 → 伊斯兰世界 / 欧洲

下一阶段不应继续无差别加边。

真正值得做的是：

> 对这几个反馈回路做“路径级 Evidence QA”：检查每一跳的年代、方向、对象、证据类型是否能够共同支撑这条探索路径。

这会比继续从273条增加到300条更有价值。
