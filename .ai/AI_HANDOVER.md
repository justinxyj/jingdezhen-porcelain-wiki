# AI Handover Protocol

1. Read PROJECT_CONTEXT.md.
2. Read CURRENT_STATE.md.
3. Read TASKS.md.
4. Read recent CHANGELOG.md.
5. Read DECISIONS.md before architecture/policy changes.
6. Inspect current GitHub main, open PRs/issues and recent CI state.
7. For database work, verify live Supabase state.
8. Identify the highest-priority task and acceptance criteria.
9. Do not repeat completed work unless verification shows regression.
10. For high-risk changes, present plan + impact + rollback + tests before execution.
11. Verify changes and update project memory.
12. Leave a clear handoff for the next session.
