# 景德镇陶瓷数字博物馆 · Jingdezhen Porcelain Wiki

**一座数字博物馆，也是一套可继续探索的景德镇陶瓷知识世界。**

把景德镇放回中国与世界陶瓷史的同一条线索上：以器物为入口，以时间解释变化，以工艺解释制造，以空间解释城市，以人物解释传承，以文献建立证据。

**在线访问：** https://justinxyj.github.io/jingdezhen-porcelain-wiki/

---

## 这是什么

本站是面向公众的 **景德镇陶瓷数字博物馆 / 知识平台**：不是普通百科词条堆砌，也不是单纯的文档仓库。访客可以在展览式浏览中进入器物、窑址、人物与工艺，再通过知识条目与关系网络继续深入。

内容范围以 **景德镇陶瓷** 为核心，并延伸到与之紧密关联的窑业、贸易、人物、遗产与研究语境。重要陈述尽量可核查、可追溯；媒体优先使用已核验的公开来源。

## 给谁看

- 对景德镇与中国陶瓷感兴趣的普通读者
- 需要按时间、空间、器物快速建立图景的学生与爱好者
- 希望从馆藏线索、窑址与文献入口继续查阅的研究者（站点提供导览与来源提示，非替代正式学术库）

## 内容原则（访客可读版）

**可核查优先**：年代、人物、窑址与器物判断尽量依据博物馆、考古、学术与可靠公开资料；区分史实、研究观点与尚存争议。图片与媒体注明来源与授权语境，优先公开可复用素材。

站点持续修订中：个别互动模块可能随数据权限与内容增补而更新；若某页暂时无法加载动态数据，仍可从专题文与博物馆总览进入阅读。

## English blurb

**Jingdezhen Porcelain Wiki** is a public digital museum and knowledge platform for Jingdezhen ceramics—not a plain documentation dump. Explore object catalogs, people, a comparative timeline, a kiln map, searchable knowledge entries, and a growing relation network, alongside structured essays on history, craft, aesthetics, kilns, research, and contemporary Jingdezhen.

**Visit:** https://justinxyj.github.io/jingdezhen-porcelain-wiki/
