# Jingdezhen Porcelain Wiki

> An open, collaborative knowledge base about the history, technology, objects, kilns, people, and contemporary culture of Jingdezhen ceramics.

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](LICENSE)

## 🌏 项目简介

景德镇陶瓷是一套跨越历史时期、工艺体系、城市空间与文化交流的复杂知识。这个项目希望把分散在博物馆、考古资料、学术研究、地方文献以及可靠公开资料中的信息，逐步整理成一个**结构化、可核查、可持续维护**的开放知识库。

项目不追求一次性“写完景德镇”，而是通过 GitHub 的版本控制和协作机制，让每个条目都可以不断补充、校对和修订。

## 📚 主要内容

| 现代景德镇 | 当代陶瓷产业、创作生态与跨界发展 |

## 🔎 内容原则

**可核查**：重要事实尽量提供博物馆、考古报告、学术专著、论文或其他可靠来源。

**可追溯**：保留资料出处，方便其他贡献者复核和继续研究。

**中立表达**：区分已知事实、研究观点和仍有争议的问题。

**尊重版权**：图片和引用内容必须符合相应许可或授权要求。
