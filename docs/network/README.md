## 七个主题如何连接

| 主题 | 主要回答 | 可以连接到 |
|---|---|---|
| 历史与发展 | 什么时候发生了什么？ | 器物、人物、窑址、工艺、文献 |
| 工艺与技术 | 一件瓷器怎样被制造？ | 器物、原料、窑炉、人物、文献 |
| 器物与美学 | 我们正在看什么？为什么重要？ | 历史、工艺、人物、文献 |
| 窑址与城市空间 | 在哪里发生？空间怎样组织？ | 历史、器物、原料、燃料、城市 |
| 人物与传承 | 谁参与了这套文明？ | 器物、窑址、历史、文献 |
| 文献与研究 | 我们凭什么知道？ | 所有主题 |
| 现代景德镇 | 今天如何继续？ | 历史、工艺、教育、产业、遗产 |

## 当前网络建设阶段

现有数据已经建立了第一层关系网络，但仍有明显的补全空间。后续优先补充**有来源支持**的历史—器物、器物—工艺、窑址—文献、人物—作品/窑址等关系。

> 重要原则：关系数量不是目标。没有可靠依据的关系不会为了“让图谱更漂亮”而人为添加。

<div class="timeline-method-note">
<strong>数据原则</strong><br>
每条关系需要说明含义与依据。关系相似不等于因果或传播；请结合对象年代、地点和出处阅读。
</div>
