## 全球比较的三个层面

器物流通、图像借鉴与生产技术传播需要分别讨论。进口瓷器可以影响观看和消费，却不自动意味着当地已经采用相同胎料；蓝白装饰的相似，也不能证明两地产品都是瓷器或具有相同烧成方式。

先核对比较对象的材料、年代与产地，再查贸易记录、出土背景和专业研究。今天海外博物馆的收藏位置不等于古代运输目的地，研究解释应保留证据范围与不同观点。
