# 版权与图片使用

本站使用的图像和引用资料可能分别适用不同的许可条件。馆藏机构名称、作品年代和照片权利属于不同信息：古代器物不受著作权保护，并不意味着其现代摄影作品可任意转载。

请先查看图片说明、来源链接及该机构针对具体图像发布的许可。故宫博物院、景德镇中国陶瓷博物馆和海外馆藏机构都是资料来源；是否可以复制、修改或用于商业用途，应以其实际授权为准。缺少许可信息的图片不能据此推定为公有领域。

[博物馆资料与图像许可](research/museum-sources.md)列出已查阅的机构与相关条款。需要反馈图像权利或标注问题，可通过[项目反馈入口](https://github.com/justinxyj/jingdezhen-porcelain-wiki/issues/new)提供对应页面、作品和权利说明。
