# 景徳鎮陶磁器デジタル博物館

**Jingdezhen Porcelain Wiki** は、中国・景徳鎮の陶磁器について、歴史、技術、器物、窯跡、人物、現代の陶磁文化を整理するオープンなデジタル博物館です。
