# 景徳鎮陶磁器デジタル博物館

**Beta · 日本語版は簡易ガイドです。記事の大半は現在、中国語で提供しています。**
景徳鎮の陶磁器を、器物、原料、制作技術、窯跡、人物、文献から読むためのサイトです。宮廷用の器と民間の製品、歴史的な生産と現代の活動を、それぞれの資料とともに紹介します。

## 器物から読む

まず名称、所蔵機関、収蔵番号、年代、材質と出典を確認します。現在の所蔵場所だけでは、古代の交易経路は分かりません。年代や帰属に幅がある場合は、その不確実性を保って読みます。
