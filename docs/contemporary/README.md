# 当代景德镇陶瓷

当代景德镇的陶瓷文化不能只用“传统手工业”概括。现有官方规划、行业研究和非遗资料显示，传统工艺、现代工业、教育科研、非遗保护与文化遗产保护共同构成今天的陶瓷文化生态。[R19][R22]

## 非遗保护

景德镇手工制瓷技艺于2006年列入第一批国家级非物质文化遗产代表性项目名录。官方资料显示，传统工艺保护包括青花、粉彩、颜色釉、古彩、玲珑瓷、青白瓷、雕塑瓷、薄胎瓷等不同技艺门类，以及传统匣钵、瓷用毛笔、釉果等辅助技艺。[R19][R22]

## 技术研究

改革开放以来，景德镇传统技艺继续与现代材料和技术研究结合。薄胎瓷研究以传承人口述史为材料，将1978年以来的发展划分为恢复、发展、过渡和创新四个阶段。[R21]

## 文化遗产保护

景德镇陶瓷文化生态保护规划把古窑址、传统作坊、历史街巷、民俗、非遗和现代文化空间作为相互关联的文化生态进行保护。[R22]

## 世界遗产后的研究框架

2026年“景德镇手工瓷业遗存”列入《世界遗产名录》后，景德镇陶瓷遗产的研究对象进一步从单一御窑或名瓷扩展到完整手工制瓷产业链，包括原料、燃料、窑炉、生产组织和城市空间。[R23]
