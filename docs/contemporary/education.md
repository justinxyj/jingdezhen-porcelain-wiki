# 教育与研究：经验、实验和陶瓷知识

陶瓷教育连接手工经验、材料科学、造型设计和历史研究。学习怎样制作，与解释为什么能这样制作，彼此相关，却不是完全相同的训练目标。

## 从师徒传承到学校教育

景德镇传统生产中，工匠通过动作、工具和协作积累知识。国家非遗项目资料记录从采矿、练泥到成型、绘饰、烧成等环节的专业化分工，说明传承对象不仅是最终外观，也包括过程中的判断。[^heritage]

景德镇陶瓷大学校史资料介绍中国陶业学堂把学理与技能结合，设置制坯、干燥与试验窑等设施，并推动学校和企业之间的联系。早期改良关注机械制瓷与燃料变化，同时重视动手训练。这个案例可以帮助理解陶瓷教育为何同时涉及科学与艺术。[^education]

## 材料实验怎样回答历史问题

科技考古把瓷胎与釉料的成分、结构和变化，与年代、出土背景及历史名称联系起来。2020年二元配方论文正是通过历史文献和检测数据，重新讨论原料开发及混配方式。结论是否成立需要审视样品和判定标准，不能只用论文作者的身份代替论证。[^materials]

## 考古与馆藏研究

御窑厂发掘提供工序空间、工具、半成品与废品，博物馆收藏提供具体传世对象。教学与研究中把两类材料对照，可以避免只按精品图像理解全部历史生产。[^kilns]

## 当代课程与研究方向

材料、工程、艺术、设计和遗产研究可以从同一件器物提出不同问题：胎釉如何反应、造型如何形成、产品怎样使用、历史归属如何确定。具体学校的专业设置、实验室、师资和招生信息应以当年的官方公布为准，不将历史校史当作现行课程表。
