# 关于本站

景德镇陶瓷数字博物馆围绕景德镇的历史、制瓷工艺、器物、人物与窑址组织资料，并介绍与中国及世界陶瓷交流有关的内容。正文结合博物馆馆藏记录、考古报告、历史文献和学术研究；不同类型的资料各有用途，不能互相替代。

条目中的参考资料用于说明材料依据。普通链接并不表示已完成事实核验；有争议的年代、归属和解释应结合原始资料阅读。图片的出处与使用许可分别列示，公开可浏览的照片不当然允许任意转载。

可从[数据来源](research/sources.md)、[博物馆资料与图像许可](research/museum-sources.md)了解资料范围。发现事实、译名、链接或显示问题，请通过[项目反馈入口](https://github.com/justinxyj/jingdezhen-porcelain-wiki/issues/new)说明页面地址、问题和可查阅的依据。

## 不使用 GitHub 的反馈方式

百科页面的“发现错误？反馈此条目”可填写问题并复制或下载反馈记录，无需 GitHub 账户。记录包含页面地址、问题说明与可选参考资料，便于转交维护者。本站目前没有匿名自动接收服务；复制、下载不代表已经发送。GitHub Issues 仍作为可选渠道保留。
