# 馆长后台入口

本页跳转至 [馆长后台](../museum/admin.md)。若未自动跳转，请点击链接。

<meta http-equiv="refresh" content="0; url=../museum/admin/">

<script>
(function () {
  try {
    var target = new URL('../museum/admin/', window.location.href).href;
    if (target.indexOf('javascript:') === 0) return;
    window.location.replace(target);
  } catch (_) {}
})();
</script>
