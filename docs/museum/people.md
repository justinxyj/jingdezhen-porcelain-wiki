## 图片与版权规则

本页采用**严格的官方来源制度**：人物照片或代表作品图片只有在能够确认来自政府部门、博物馆、文化和旅游主管部门或官方机构网页时才进入数据库。当前已经直接核验到的两张图片来自文化和旅游部恭王府博物馆与景德镇中国陶瓷博物馆联合主办的“月圆逸韵”官方展览页面，分别为王琦、田鹤仙的馆藏作品。该官方资料同时列出王琦、王大凡、汪野亭、程意亭、徐仲南、田鹤仙、邓碧珊、刘雨岑、何许人、毕伯涛以及王步等同期名家。

对于现代人物，本轮先完成**官方人物资料、简介和来源链**。由于当前能直接验证的官方人物图片 URL 不足，我没有混入搜索引擎转载图、百科头像或第三方肖像图；取得对应官方图片地址后再补入。

## 人物关系模型

最终每个人物将关联：`姓名 / English / 日本語 / 生卒 / 时代 / 身份 / 师承 / 技艺 / 代表作品 / 活动地点 / 窑址 / 机构 / 文献 / 官方图片 / 图片许可 / 核验状态`。

下一层关系将连接：**人物 → 作品 → 工艺 → 窑址 → 机构 → 历史时期 → 世界比较时间轴**。

## 史料依据

景德镇市政府公布的《景德镇陶瓷文化生态保护区总体规划（2021—2035年）》系统梳理了景德镇从早期窑业、宋代青白瓷、元代青花、明代御窑到清代彩瓷以及近现代产业转型的历史脉络。景德镇中国陶瓷博物馆官方介绍显示，该馆藏品五万余件，并重点收藏展示王步、珠山八友等近现代艺术陶瓷精品。

文化和旅游部恭王府博物馆的“月圆逸韵——景德镇珠山八友主题瓷绘作品特展”官方资料，是本页近代瓷绘人物与官方展览图片的重要来源。
