# 历史时间轴

时间轴中的节点只使用已经进入文献库的历史事实、考古发现或正式文化遗产资料。交互页面由 `museum.js` 读取数据，并在每个节点保留 `[Rxx]` 文献标识。

<div id="timeline"></div>

## 时间轴阅读方法

时间轴不是简单的朝代列表，而是把**城市建置、窑址、技术、生产组织、贸易和遗产保护**放在同一条历史线上。[R01][R03][R07][R23]

### 证据层级

- 考古节点：优先引用考古发掘报告。
- 技术节点：引用科技史、工艺史研究和行业志。
- 制度节点：引用地方志、历史文献和御窑考古资料。
- 世界遗产节点：引用 UNESCO 和正式申遗资料。

## 数据原则

以后增加时间轴节点时，必须同时增加参考文献。没有出处的“某年发明”“世界第一”“唯一”等说法不进入时间轴。

详见[文献研究规范](../research/README.md)与[核心文献库](../research/sources.md)。
