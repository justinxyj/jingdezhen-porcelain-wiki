# 图片库

图片库的核心不是“堆图片”，而是给每张图片建立可追溯元数据：拍摄/收藏地点、对象 ID、作者、来源、许可、时间与核验状态。

## 图片入库规则

1. 必须记录原始来源 URL 或馆藏来源。
2. 明确版权/许可，不直接抓取受版权保护的图片。
3. 建议保存作者、拍摄日期、地点、对象 ID、许可协议与修改历史。
4. 用户上传图片先进入待审核区，不直接覆盖公共资料。

> 后续接入 Supabase Storage 后，这里可以升级成真正的上传、标签、搜索与审核图片库。
