## 图片入库规则

1. 必须记录原始来源 URL 或馆藏来源。
2. 明确版权/许可，不直接抓取受版权保护的图片。
3. 建议保存作者、拍摄日期、地点、对象 ID、许可协议与修改历史。
4. 用户上传图片先进入待审核区，不直接覆盖公共资料。

> 图片上传、标签、搜索与审核将逐步接入 Supabase Storage；当前页面先保证元数据结构和可追溯性。
