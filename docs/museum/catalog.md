## 推荐字段

`ID / 中文名 / English / 日本語 / 年代 / 器型 / 胎质 / 釉 / 装饰 / 工艺 / 尺寸 / 用途 / 出土地点 / 收藏机构 / 馆藏编号 / 图片 / 来源 / 版权 / 核验状态 / 参考文献`

## 核验规则

- 考古出土器：记录发掘地点、地层和考古报告。
- 馆藏器：记录收藏机构和馆藏编号，并优先引用官方馆藏资料或正式图录。
- 传世器：必须区分“传世信息”和“考古年代证据”。
- 断代结论：不能只凭图片、颜色或单一纹饰判断。
- 存在学术争议：保留不同研究观点并标出来源。

## 当前图谱的资料基础

青白瓷、青花、粉彩、颜色釉四类条目的基础知识分别来自湖田窑考古、青白瓷研究、明代御窑青花研究、粉彩工艺研究和颜色釉研究。[R01][R09][R16][R25][R30]
