## 权限模型

- **游客**：浏览、搜索、查看地图与图谱。
- **注册用户**：收藏、提交编辑、上传资料（待审核）。
- **审核员**：审核编辑、处理来源与版权问题。
- **管理员**：管理用户、数据模型与站点设置。

目前公共网站使用 GitHub Pages 静态托管，因此账户数据与编辑数据需要独立的后端数据库。
