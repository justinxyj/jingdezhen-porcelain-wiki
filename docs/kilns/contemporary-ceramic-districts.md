# 当代陶瓷产业空间：生产、创作与公共文化

观察景德镇当代陶瓷空间，需要区分正在使用的生产设施、创作者工作室、学校与实验室、展览空间以及文化旅游场所。它们可能集中在同一区域，也可能以服务和交易相联系，功能不应仅由一个“陶瓷园区”标签概括。

## 从工序认识空间

练泥、成型、修坯、彩绘、施釉和烧成各有工具、劳动与环境需求。传统生产分工的资料可以帮助提出今天的空间观察问题：哪些环节仍在现场进行，哪些由外部服务完成，原料和半成品怎样在地点之间移动。[^heritage]

## 老厂房与新用途

历史工业建筑可以被继续生产、改作展示、教学或商业空间。介绍更新项目时，应分别记录原有用途、改造阶段和当前用途；“保留建筑”与“保留工艺”不是同一个结果。有关保护与运营的评价，还需考虑使用者、工匠和周边生活的资料。

## 地图怎样记录当代地点

位置应对应具体地址或公开坐标，机构名称、开放状态和服务内容按查阅时间记录。不能把管理机构的地址当作全部活动范围，也不能用城市中心点代替一个尚未核实的作坊位置。

## 比较需要什么数据

建筑面积、投资额、入驻数量、就业与游客人数采用不同口径。只有说明年份、统计范围和发布机构，才能在地点之间比较。一个招商目标不能改写为已经实现的成果，曾经开放的场所也不能未经核对写成今日仍开放。
