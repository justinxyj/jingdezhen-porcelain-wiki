# 御窑厂遗址：宫廷瓷器的生产端

御窑厂遗址位于景德镇珠山一带，是研究明清宫廷制瓷的重要生产遗址。它保存的意义不仅在于发现精美瓷器，还在于把产品放回作坊、工具、窑炉、选验与废弃物处理的关系中。

## 两次主动发掘

北京大学考古文博学院介绍，2002—2004年联合发掘揭露围墙、窑炉、辘轳坑及落选御用瓷器掩埋坑。2014年在遗址中部西侧开展400平方米发掘，清理各阶段遗迹64处，揭露元代后期至清末民国地层，并发现明中期釉上彩作坊。[^kilns]

该资料依据元代和明初地层，提出明御器厂始建于洪武末期。这里应区分窑业在这一区域原有的基础、御器厂制度的建立，以及后来建筑和生产分区的变化，不能把整个地点的历史压缩成一个“建厂年份”。

## 瓷片坑与选验

落选御用瓷器及其废弃堆积保存了成品收藏之外的证据。器物被淘汰的原因、处理方式和坑的形成时间，需要结合具体组合研究；“被打碎”不等于每件都只是技术失败。器物拼合与修复可以重建形态，却不能替代原始出土记录。

## 从器物类型学到生产制度

作坊遗迹、辘轳坑、加彩半成品、窑具和成品共同帮助理解工序如何安排。北大资料将2014年发掘与以往发现结合，讨论明中期成型区、加彩区、生产区和选余品埋藏区的分布关系。遗址不是一幅从明初到清末都不改变的平面图，应按时期分别阅读。[^kilns]

## 与故宫馆藏怎样对照

窑址材料回答“在哪里、怎样生产”；故宫等机构的传世器物回答特定对象的收藏、定名和使用线索。比较时需要核对形制、纹饰、胎釉、款识与年代，不因外观相近便认定某件传世器出自某一个瓷片坑。

遗址保护、博物馆展示与学术研究各有目的。展示中完整的修复器，应与考古发表中的原始信息一起理解。继续阅读[明清专题](../history/ming-qing.md)与[博物馆资料目录](../research/museum-sources.md)。
