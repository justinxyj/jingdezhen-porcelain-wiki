# 御窑厂遗址

## 遗址性质

御窑厂是明清时期景德镇宫廷用瓷生产体系的核心遗址之一。研究御窑厂不能只看传世名瓷，还要观察窑炉、作坊、窑具、瓷片堆积和落选品处理方式。[R03]

## 2002—2004年考古发掘

北京大学考古文博学院与江西省文物考古研究所、景德镇市陶瓷考古研究所联合发掘珠山北麓、南麓，面积1578平方米。发掘清理了围墙、窑炉、辘轳坑以及掩埋落选御用瓷器的瓷片坑和片状堆积等遗迹。[R03]

出土材料包括瓷器、建筑瓦件、窑具等。永乐、宣德、成化、弘治、正德等时期的瓷器残片数量较多，并发现部分传世品中少见的器物和装饰工艺。[R03]

## 2014年发掘

2014年第二次大规模主动性发掘揭露了元代后期至清末民国时期的地层，清理作坊、灰坑、房址、道路、庭院、辘轳坑等遗迹64处，并首次发现明中期生产釉上彩瓷的作坊。[R03]

这一发掘还帮助研究者理解御窑厂不同生产区域之间的关系，包括成型、加彩、生产以及落选品埋藏等空间功能。[R03]

## 官作与城市

官方陶瓷文化生态保护规划指出，景德镇的官窑和民窑长期共同存在，官作并没有与民窑形成完全隔绝的技术体系，人员和技术的流动促成了两者之间的交流。[R22]

## 研究意义

御窑厂考古把研究从“名品鉴赏”推进到生产史：通过遗迹、工具、窑具、原料和废弃物，可以研究官手工业的生产组织、空间分工和制度变化。[R03][R04]
