# 窑址与历史遗存

景德镇陶瓷史必须落到具体遗址。窑址、作坊、原料产地、燃料产区、城市街区和码头共同构成制瓷产业的空间系统。[R01][R03][R23]

## 世界遗产体系中的五个组成部分

2026年列入《世界遗产名录》的“景德镇手工瓷业遗存”由五个部分组成，覆盖镇区瓷业生产中心、湖田古瓷窑址、高岭瓷土矿遗址、长岭瓷石矿遗址和蛟潭窑柴燃料产区。[R23][R24]

这一结构非常重要：它把“窑址”从单独的烧窑地点扩展为完整产业链，包括原料、燃料、生产、城市组织和贸易。[R23]

## 研究原则

具体窑址的年代、范围、产品和性质应优先依据考古报告。后世地方传说可以作为民俗史研究对象，但不能直接替代考古证据。[R01][R03]

## 遗址与城市

官方陶瓷文化生态保护规划统计了景德镇古瓷窑址、古窑房、传统作坊、码头及瓷业民俗等多种遗存，强调官窑、民窑、生产空间和社会组织共同构成景德镇陶瓷文化景观。[R22]
