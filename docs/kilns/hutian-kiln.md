# 湖田窑

## 遗址与年代

湖田窑是景德镇最重要的古窑址之一。江西省文物考古研究所与景德镇民窑博物馆编著的《景德镇湖田窑址：1988—1999年考古发掘报告》以多次发掘材料建立了五代、北宋、南宋、元、明等阶段的遗存序列。[R01]

研究者据大量考古发掘资料认为，湖田窑的烧造活动从五代延续到明代后期，持续时间超过七百年；不同阶段生产白瓷、青瓷、青白瓷、黑釉等多种产品，其中青白瓷最具代表性。[R10]

## 青白瓷

宋代湖田窑青白瓷具有胎体细白、釉色青白和透明度较高等特征。相关研究把宋代青白瓷分期与器型、装饰技法的变化结合起来讨论。[R09][R10]

## 生产遗迹

湖田窑考古资料不仅包含瓷片，还包括窑炉、作坊、窑具和制瓷工具等遗迹。地方行业志整理的考古资料指出，五代至宋代中期已经可以观察到拉坯、过范、修足等成型环节。[R08]

## 学术意义

湖田窑的重要性在于它提供了较长时间连续的地层和产品变化材料，使研究者能够把景德镇民窑的技术变化与具体考古背景联系起来，而不是只依赖传世器物。[R01][R12]
