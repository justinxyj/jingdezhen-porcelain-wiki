# 湖田窑：从长期窑业遗存理解青白瓷

湖田窑是景德镇陶瓷考古的重要对象。阅读这一遗址，需要把不同阶段的生产活动、出土器物和窑具放在一起，而不是将整个窑址视为一个只生产单一品种的“宋代窑”。本站既有书目列有《景德镇湖田窑址：1988—1999年考古发掘报告》；详细遗迹编号与分期应以正式报告为依据。

## 青白瓷与生产方法

青白瓷把白胎、带青色调的釉和刻划或模印装饰结合起来。釉层在纹样凹处积聚，会影响观看到的颜色与层次。器型、装饰和釉面应联合观察，不能只根据一种青绿色调认定产地。

国家非遗项目介绍，宋代景德镇已采用拉坯、印坯、利坯、修足及多种装烧方法。这些区域性的工艺记述可以帮助提出湖田窑研究的问题，但具体工序在湖田某一期是否存在，仍须由该期遗迹和器物支持。[^heritage]

## 地层为什么重要

地层与同出组合可以约束器物的时间关系。窑场往往持续生产并改建，废弃物也可能被搬运或用于填垫，因此瓷片在遗址中出现并不自动等于它在该处的堆积年代被烧制。研究需要解释出土情境，区分原生堆积与后来的再沉积。

## 原料研究中的湖田材料

2020年二元配方论文回顾了此前根据湖田元代器物胎体铝含量提出元代起源说的研究，再以天然伴生原料与人为混配的区别重新解释这类数据。湖田材料因此不只服务于“发现了哪种器物”，也进入原料史和方法论讨论。[^materials]

## 怎样与御窑比较

比较湖田与[御窑厂](imperial-kiln.md)时，应区分时间范围、管理制度、产品组合和考古样本。御用精品与民窑废弃物受到不同选择过程影响，不宜直接以完整程度或视觉精美程度判断整个窑场的技术高低。

参阅[宋元专题](../history/song-yuan.md)与[青白瓷相关书目](../research/sources.md)。
