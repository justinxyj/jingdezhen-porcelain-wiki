# 原料产地、燃料与其他瓷业遗存

窑炉之外，制瓷还依赖原料开采、加工、运输和燃料供给。把这些地点与作坊、窑场、码头和市场一起阅读，可以更完整地理解景德镇瓷业的空间关系。

## 高岭与瓷石原料

2020年二元配方论文讨论景德镇周边的瓷石和高岭土矿床，指出天然伴生与不同风化程度会影响原料的铝含量。矿区名称、文献中的土名和具体矿物组成需要核对，不能认为所有名称中出现“高岭”的材料，都等同于经过选择的人为配方中的高岭土。[^materials]

论文还将明代嘉靖至万历时期高岭土的大规模开发，与明末清初人为二元配方的出现联系起来。这个解释来自文献与样品数据的综合研究；遗址说明应保留其研究归属。

## 燃料与烧造

燃料影响窑炉运行，也涉及采集、运输、储存和劳动。柴窑不能只作为一种怀旧风格介绍；其实际烧造条件与资源供给属于技术和社会史问题。近代陶业学堂推动煤窑试验的校史，展示了燃料与窑炉技术转型的具体联系。[^education]

## 作坊、道路与废弃物

御窑考古同时发现道路、房址、作坊和瓷片坑。这类遗存使研究从单件器物延伸到生产组织。一个地点的功能可以随时期改变，地图上的固定标记不能代替分期研究。[^kilns]

## 遗产名录与地点身份

遗址、矿区、窑房、历史街区、博物馆与现代工作室是不同对象。介绍保护级别、遗产组成部分或边界时，应直接核对对应正式文件，避免仅凭相邻位置将它们当成同一个保护单元。
