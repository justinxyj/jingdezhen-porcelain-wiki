# 纹饰与题材

纹饰研究不能脱离器型、时代、生产体系和装饰工艺。御窑厂考古显示，同一时期出土器物的器型和纹饰组合十分丰富，因此纹饰既是审美信息，也是器物类型学和生产研究的重要材料。[R03]

## 宋元青白瓷

宋代景德镇青白瓷的研究关注刻花、印花等装饰方法。相关研究还把“半刀泥”刻花作为专题，讨论其装饰特征与历史演变。[R09][R14]

宋元青白瓷人物造像的研究则显示，人物造像技术涉及造型语言、材料、装饰和烧成多个层面，不能只作为“图案”来理解。[R15]

## 明清题材

明清御窑考古出土材料包含丰富的器型和纹饰组合，研究者可以通过地层和遗迹把纹饰与具体生产阶段联系起来。[R03]

青花、粉彩等装饰体系还受到不同绘画传统影响。粉彩研究尤其关注宫廷绘画、文人画和外来绘画技法等因素在装饰语言中的作用。[R25][R26]

## 纹饰研究方法

分析一件器物的纹饰时，应同时记录：

- 主题题材
- 构图方式
- 主次纹饰关系
- 纹饰与器型的对应
- 绘画或刻划工具留下的痕迹
- 所属装饰工艺
- 出土或传世背景
- 同时期可比较器物

“龙纹=官窑”“某种花纹=某个年代”等网络简化规则不能作为 Wiki 的断代依据。[R03][R16]
