# 釉色与装饰技法

陶瓷的视觉效果来自胎体、釉层、彩料、装饰位置和烧成条件的共同作用。因此“颜色”与“装饰技法”必须分开记录。[R08][R30]

## 釉下装饰

青花属于釉下彩绘：含钴彩料先绘于胎体，再施透明釉并高温烧成。钴料、绘画和烧成条件共同影响最终发色。[R08][R16]

## 釉上装饰

粉彩属于釉上彩绘体系，其工艺发展与康熙五彩、珐琅彩等传统存在联系，并在雍正、乾隆时期形成不同的技术与艺术风格。[R25][R27]

## 颜色釉

颜色釉主要依靠釉料组成和着色元素在烧成后形成视觉效果。清代祭红釉的研究表明，釉层显微结构、化学组成与烧制工艺会共同影响呈色。[R30]

## 阅读器物

观察釉色和装饰时，可以按以下顺序记录：

1. 胎体颜色和质地
2. 釉层厚薄与透明度
3. 装饰位于釉下还是釉上
4. 彩料或釉色的呈色特征
5. 刻、划、印、绘、堆塑等工艺痕迹
6. 烧成造成的窑变、流釉等现象
7. 考古或收藏背景

## 研究边界

颜色相似不等于工艺相同；名称相同也不一定代表每个历史阶段的配方完全一致。Wiki 只在有文献支持时使用确定性表述，并把不同研究的术语差异保留下来。[R04][R25][R30]
