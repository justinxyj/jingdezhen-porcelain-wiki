# 博物馆馆藏、图像与研究资料

景德镇陶瓷研究需要把产地考古、传世器物和历史文献放在一起阅读。景德镇本地机构提供窑业与城市的材料；故宫博物院的馆藏及研究资料可用于讨论宫廷用瓷；海外博物馆的收藏记录则提供比较器物与跨地域流通的线索。不同机构的资料各有范围，不能把某一家博物馆的藏品当作景德镇陶瓷史的全部。

故宫博物院和景德镇中国陶瓷博物馆是重点资料来源，但机构首页只是检索入口。为具体器物断代、解释工艺或引用展览观点时，应进一步指向对应藏品记录、文章或图录页码。故宫相关学术文献还可从[核心文献库](sources.md)中已有的《景德镇瓷器生产“二元配方”起源初探——兼论高岭土开发史》开始检索；论文结论应结合全文中的样本、方法与适用范围阅读。

## 图书馆与跨语际文献

[法国国家图书馆“Porcelaine”专题](https://heritage.bnf.fr/france-chine/porcelaine)由Jean-Pierre Drège撰写，联系殷弘绪通信、杜赫德编纂、制瓷图册和《景德镇陶录》法译。它适合研究器物贸易之外的知识传播；所链接图册仍须逐项核对对象记录与使用条件。

## 怎样阅读一条馆藏记录

先确认图片对应的对象，再核对器物名称、馆藏编号、年代、材质、尺寸、窑口或产地、铭文及收藏信息。馆方采用“归属”“约”“可能”等表述时，本站应保留相应的不确定性。不能把“青花”“中国”或一个朝代标签直接改写为“景德镇御窑”，也不能仅凭纹饰相似就认定存在传播关系。

馆藏所在地与器物的历史流通路径是不同信息。今天在欧洲或美国收藏，并不能单独证明该器物在制作年代就曾经出口当地。讨论外销与交流，应结合出土地点、贸易文献、收藏记录和专门研究。

## 图片的来源与使用许可

可靠来源回答“这张图是否对应可信的对象记录”；许可回答“本站是否可以以这种方式使用图片”。二者必须分别核对。古代器物的年代、官方机构的身份，或官网可以打开的图片地址，都不能单独证明摄影图像可自由转载。直接调用外部图片链接也不是获得授权的替代办法。

每张正式入库图片至少保留以下信息：

- 对应条目、器物全名、收藏机构及馆藏编号。
- 图像地址和具体来源页面；需要时记录摄影者或机构署名。
- 许可名称、许可或使用条款链接，以及适用的展示、复制和修改限制。
- 核验日期、核验依据及署名文本。未知信息明确记录为未知，不填写推测的授权。

明确开放的图像按其许可使用；需要授权的图像在取得授权后使用；只有对象资料可引用而图像权利不明时，保留官方藏品链接，不复制或嵌入该图片。Wikimedia Commons 图片也应核对具体文件页、原始来源与许可，不能因为文件出现在 Wikipedia 就跳过这些步骤。

## 从资料到正文

博物馆对象记录用于支持其记载的器物信息；论文用于支持研究者实际论证的结论；考古报告用于支持发掘情境和生产遗存。正文应把“馆方定名”“研究者提出”与本站的比较解释区分开来，并在相应句段旁提供出处。

Wikipedia 和百度百科可用于寻找术语、人物及参考文献线索。涉及年代、首创、材料来源、窑口归属与历史影响的论断，应追查原始文献或专业研究，避免将多个互相转载的页面误认为独立证据。具体写作方法见[文献研究与知识编纂规范](README.md)。
