# 文献研究与知识编纂规范

本 Wiki 的知识正文采用**文献证据优先**原则：没有可核验出处的内容不写入事实性正文；网络传说、营销文案、个人鉴定、无法追溯出处的“常识”不作为知识来源。

## 当前证据层级

1. **考古发掘报告**：用于窑址年代、地层、遗迹、出土器物和生产空间等核心事实。
2. **正式出版的地方志、行业志和历史文献**：用于建置、制度、生产组织、工艺记载和历史语境。
3. **博物馆、文博机构和高校公开学术资料**：用于馆藏、考古成果、研究综述和非遗项目资料。
4. **同行评议论文及学位论文**：用于专题研究、技术史、器物史和学术争议。
5. **原始古籍公开文本**：用于直接核对古代文献记载，但古籍记载与现代考古结论必须分开表达。

## 编纂规则

- 每一个重要历史断言都应能回溯到参考文献。
- 文献明确记载的事实、考古发现和研究者观点分别表述，不把观点写成无争议事实。
- 不以单张网络图片、短视频、商业宣传页或无出处百科内容进行断代、鉴定或历史判断。
- 文献之间存在争议时，同时记录不同观点，并注明争议来源。
- 当代数据必须标明年份、统计口径和发布机构。
- 本站不是古陶瓷鉴定平台；不能由单一器型、颜色或纹样直接推出年代、真伪或产地。

## 本轮资料范围

本轮先建立可公开核验的核心资料库，覆盖：景德镇建置史、湖田窑考古、明清御窑考古、青白瓷、青花与釉里红、原料与“二元配方”、制坯技术、装饰技术、外销瓷、近现代瓷业、非遗以及世界遗产资料。

> “所有景德镇相关文献”是一个持续增长的学术文献集合，不可能在一次更新中穷尽。Wiki 因此采用可扩展书目库：后续新增文献时，应同步更新正文与书目，而不是把未核验的网络信息补进正文。
