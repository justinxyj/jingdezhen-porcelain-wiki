# 文献研究与知识编纂规范

景德镇陶瓷的历史涉及原料、烧成、器物、生产制度、贸易和城市生活。不同问题需要不同证据：考古报告说明出土情境，馆藏记录说明具体收藏对象，历史文献保存当时的表述，材料分析与专题论文提出可检验的解释。正文应让读者看到事实的依据和解释的边界。

## 先确定问题，再选择资料

| 研究问题 | 优先查阅 | 需要保留的限制 |
| --- | --- | --- |
| 窑址何时生产、生产什么 | 发掘报告、地层记录、出土器物组合 | 某次发掘的范围不等于整个遗址的全部历史 |
| 某件器物如何定名、断代、归属 | 收藏机构的对象记录、正式图录、相关研究 | 保留馆方的约略年代和归属措辞；来源不明的器物不能强加出土背景 |
| 胎釉、彩料与烧成如何变化 | 科技考古论文、样品数据、工艺史研究 | 样品数量、取样部位、测试方法及比较对象决定结论适用范围 |
| 御窑制度、劳动分工、贸易如何运行 | 古籍、档案、地方志、考古与历史研究 | 后世记述不能未经说明就作为早期事件的同时代证据 |
| 当代产业、教育和遗产状况 | 正式统计、机构档案、政策文件、官方决定 | 标明年份、统计口径和文件性质；规划目标与实际结果分别表述 |

故宫博物院、景德镇中国陶瓷博物馆及海外博物馆的资料均纳入检索范围，具体入口见[博物馆资料目录](museum-sources.md)。Wikipedia 和百度百科用于检索术语、问题及其引用线索；涉及关键事实时继续追查原始出处。多个网页引用同一篇文章，不构成多个独立证据。

## 专题正文的写法

导语先说明对象是什么、涉及何时何地，以及它在陶瓷史中的具体位置。正文围绕可回答的问题展开，而不是重复“历史悠久”“技艺精湛”等评价。工艺专题解释材料、制作顺序、烧成条件与可观察的效果；历史专题交代时间范围、生产组织、市场和变化；窑址专题说明位置、发掘、生产年代、产品与遗迹；人物专题介绍活动背景、可证实的作品或工作和相关影响。

器物条目记录名称、收藏机构、编号、尺寸、材质、工艺、馆方断代及相关出处，再解释其造型与装饰。器物在今天的收藏地点不自动代表其古代流通目的地。人物的声誉、器物的市场价格与生产规模也不是同一种信息，不能互相替代。

## 事实、解释与争议

使用“出土”“文献记载”“馆方定名”“研究者认为”等准确表述，让读者知道证据来自哪里。关于“最早”“首创”“唯一”“世界遗产正式列入”等结论，应核对能直接支持该说法的材料，不能只根据摘要、展览宣传或新闻标题扩大解释。

学术争议应说明分歧发生在哪个定义、年代或证据上，再分别介绍研究者的样本和论证。不能把一个研究者的新结论写成所有研究已经接受的事实，也不能把资料不足说成已经证实不存在。对古籍的引文注明篇章与版本；现代转述与原文引用分开，保留必要的年代背景。

论文选择应考虑研究问题的相关性、数据和方法是否透明、是否经过学术审查，以及与后续研究的关系。“最新”不自动等于最可靠，博士论文也不自动高于考古报告。只能读取摘要时，记录阅读范围，不据此描述未读到的实验细节或全文结论。

## 引用与书目

重要句段的出处放在相邻位置，让读者能够分辨一条来源支持哪项论断。论文记录作者、题名、刊物、年份、卷期、页码及 DOI（如有）；专著记录版次、出版信息和页码；网页记录发布机构、页面标题、具体地址与查阅日期。机构首页用于导航，不替代具体证据页面。

现有 R 编号用于保持正文与书目的对应；重编时须核对书目本身和引用是否准确，不因旧稿已有编号就认定已经完成核验。外文馆藏术语采用审慎的中文译名，并在可能产生歧义时保留原称。引文尽量短且确有必要，正文采用独立组织的表达，不整段复制百科、展签或论文。

## 图片与资料的关系

图片应与条目对象或明确标注的比较对象对应，保留来源页面、馆藏编号、摄影署名和许可依据。官方来源的可信度与摄影图片的转载许可分别核对；没有明确依据时不填写“公共领域”或“已授权”。缺少可靠肖像、遗址现场图或工序照片时，可保留文字说明与来源链接，不用无关器物代替。
