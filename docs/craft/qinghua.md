# 青花（Qinghua / Blue-and-White Porcelain）

青花瓷通常以含钴颜料在瓷胎上绘画，再施透明釉并经高温烧成，使蓝色纹饰呈现在釉下。景德镇是中国青花瓷生产与传播史上的重要中心之一。

## 核心工艺

一般可从以下环节理解青花装饰：

1. 制备并处理瓷胎
2. 在坯体表面绘制青花纹样
3. 施透明釉
4. 高温烧成
5. 出窑后检查发色、釉面和器形

具体材料配方、绘画工具、施釉方式与烧成条件会因时代、窑场和生产体系而变化。

## 视觉特征

青花最直接的视觉特征是白地上的蓝色装饰，但具体发色会受颜料来源、成分、绘画厚薄、窑内气氛以及烧成条件等因素影响。因此不能仅凭“蓝色深浅”判断器物年代或产地。

## 历史研究

研究具体青花器物时，应结合器型、胎釉、纹饰、工艺痕迹、出土/传世信息及可靠的科学检测或考古资料进行判断，避免仅依据网络图片作断代。
