# 制瓷工艺概览

景德镇制瓷不是单一工序，而是一套由原料加工、成型、修整、装饰、施釉、干燥和烧成等环节组成的生产体系。不同器物、时代和工坊的具体工艺并不完全相同，因此本 Wiki 使用“工艺链”来组织知识，而不是把某一种固定工序数量视为所有历史时期的唯一标准。

## 工艺链

1. 原料与胎土处理
2. 成型
3. 修坯与干燥
4. 装饰
5. 施釉
6. 烧成
7. 检验、整理与后续加工
