# 颜色釉

颜色釉不是单一颜色，而是一组通过釉料组成、着色元素与烧成制度形成不同色彩和表面效果的技术体系。[R08]

## 明代颜色釉

文献与出土资料显示，明代景德镇颜色釉体系包括不同阶段的白釉、红釉、蓝釉、黄釉、绿釉等品种，并与宫廷用瓷和祭祀制度存在关系。[R29]

知识细颗粒资源库整理的相关资料指出，霁红（祭红）在明初已经形成成熟烧制传统；霁蓝则属于以钴为发色剂的高温蓝釉，明清时期持续生产。[R29]

## 清代颜色釉

清代康熙、雍正、乾隆时期颜色釉继续发展。相关研究以清代官窑祭红釉残片为对象，通过显微结构、化学组成和色差分析研究釉层结构、配方、烧制工艺与呈色之间的关系。[R30]

中国非物质文化遗产网发表的研究资料还结合《景德镇陶录》《南窑笔记》等文献讨论清初高温铜红釉，指出康熙时期霁红、郎窑红、豇豆红等品种在原料配制和烧成方面存在技术联系。[R31]

## 为什么颜色不能单独用于断代

颜色釉的呈色受到釉层结构、化学组成和烧制工艺共同影响。[R30] 因此，不能仅凭照片中的红、蓝、绿等颜色判断一件器物的年代或窑口。
