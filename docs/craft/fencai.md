# 粉彩（Fencai / Famille Rose）

## 起源与发展

现有研究通常把粉彩的形成放在清代康熙晚期至雍正时期。清华大学博士论文《粉彩工艺与艺术风格的演变》认为，粉彩工艺产生于康熙晚期，雍正时期发展成熟，其形成受到清宫画珐琅和景德镇传统五彩两方面影响。[R25]

景德镇陶瓷大学研究也指出，粉彩的工艺基础与康熙五彩、珐琅彩存在关系，而清中期宫廷花鸟画风又影响了粉彩花鸟装饰的形式和风格。[R26]

## 工艺特征

粉彩属于釉上彩绘体系。研究涉及彩料、玻璃白、绘彩技法和低温彩烧等问题；其中“渲染”使颜色出现浓淡和明暗层次，是粉彩视觉效果的重要组成。[R25][R27]

## 雍正与乾隆

相关研究显示，雍正时期粉彩在器型、胎釉和绘画技法方面得到成熟发展；乾隆时期则进一步出现多种装饰技法组合，官窑和民窑均有大量生产。[R25][R27]

## 现代研究

当代研究继续讨论粉彩颜料、工艺流程及材料安全问题。例如景德镇陶瓷大学相关研究专门讨论传统粉彩颜料的无毒化和材料改良。[R28]
