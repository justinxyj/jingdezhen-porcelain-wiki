# 成型与修整

景德镇传统制瓷的成型并非一个动作，而是由制坯、修整、施釉和烧成等相互衔接的工序构成。地方行业志与非遗项目资料可以相互印证其中的历史层次。[R08][R19]

## 传统成型体系

景德镇市瓷业志将日用陶瓷成型归纳为可塑法和注浆等体系，其中可塑法包括模印、拉坯、雕塑、旋压、滚压等方法。[R08]

考古资料显示，五代至宋代中期，湖田、湘湖等窑场的成型已经发展出拉坯、过范、修足等工序，并出现铁刀镟削等修整方法。[R08]

## 拉坯、利坯与修足

拉坯形成基本器形后，还需要通过利坯等修整工序控制胎体厚薄和器壁形态。修足则进一步处理器底与足部。景德镇手工制瓷技艺的国家级非遗资料也把拉坯、印坯、利坯、修足列为传统成型体系的重要环节。[R19]

## 施釉前后的关系

制坯完成后还要经历干燥、施釉等环节。不同产品采用的施釉方法并不完全相同，古代文献、考古遗存与近现代行业技术不能简单合并成一套固定流程。[R08][R19]

## 专业化分工

国家级非遗资料指出，明清时期景德镇手工制瓷形成高度细化的分工体系，原料加工、成型、装饰、施釉、烧成和辅助环节相互衔接。[R19]

“工序很多”并不意味着每一件历史器物都严格执行同一套固定流程；具体工艺仍应结合时代、器物类型和生产地点判断。[R19]
