# 窑炉与烧成

景德镇陶瓷技术史不仅是坯、釉和彩料史，也是窑炉、窑具、装烧方法和燃料组织的历史。[R08][R19]

## 装烧技术

国家级非遗资料记载，宋代景德镇手工制瓷已经使用匣钵仰烧、垫钵覆烧、支圈覆烧等装烧方法。这些方法与器物支承、变形控制、装窑效率等问题相关。[R19]

## 窑具与生产

考古发掘不仅出土瓷器，也会出土匣钵等窑具。御窑厂考古资料表明，窑具、工具、窑炉和作坊遗迹可以与瓷片共同用于重建生产过程，而不应只研究传世完整器物。[R03]

## 御窑生产

2002—2004年御窑厂发掘清理了保存较好的窑炉遗迹，并发现了处理落选御用瓷器的瓷片坑和堆积。2014年发掘又揭露了不同阶段的作坊、灰坑、房址、道路、庭院和辘轳坑等遗迹。[R03]

这些考古证据说明，御窑研究应同时观察“窑炉—作坊—窑具—产品—废弃物”的完整生产链，而不能只把御窑理解为一个烧窑地点。[R03]

## 烧成条件

青花等装饰的最终颜色与呈色效果受到颜料成分、绘画厚薄、釉层和烧成条件等多因素影响。具体器物的烧成制度需要结合科学检测和考古资料，不宜凭照片颜色直接判断年代。[R08][R16]
