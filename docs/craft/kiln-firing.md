# 窑炉与烧成：火、窑具和装烧制度

瓷器烧成是坯料和釉料在加热过程中发生反应并形成最终结构的过程。窑炉提供热环境，装烧方法决定器物怎样被支承和隔离，燃料与操作则影响温度及气氛。研究烧成不能只给出一个最高温度，还要观察窑炉结构、升温过程、器物位置和烧后结果。

## 装烧与支承

国家非遗资料记载，宋代景德镇采用匣钵仰烧、垫钵覆烧和支圈覆烧等方法。不同方法改变支承位置、釉面处理和装窑方式，因而会在口沿、足部或器内留下不同痕迹。匣钵、垫具和支圈是生产工具，也是在考古中识别装烧方式的重要材料。[^heritage]

烧成中的收缩和高温软化，使坯体存在变形风险。装烧既要考虑支承，也要安排器物间距、气流和热量分布。器物粘连、坍塌或过烧的废品，可以提供单看精品不易发现的生产问题。

## 窑炉与原料的协同变化

2020年原料论文把高岭土配制、瓷胎耐火性能与清初镇窑发展联系起来讨论。研究说明，原料不是脱离烧成设备的独立“发明”；更耐火的坯料也需要匹配的烧成条件。具体历史阶段的温度与配方须依据检测和遗迹，不能从照片色彩直接反推。[^materials]

## 作坊、产品与废弃物

御窑厂2002—2004年和2014年的考古，把窑炉、作坊、工具、瓷片坑及半成品联系起来。2014年明中期釉上彩作坊的发现，说明彩绘和后续烧成应作为完整生产过程研究，而不只是对传世器物的纹饰分类。[^kilns]

## 高温成瓷与后续彩烧

青花纹样位于釉下，通常随胎釉烧成；粉彩等釉上装饰在已有釉面上施彩，再经相应彩烧固定。不同工艺的温度与气氛需求不同，“一件瓷器烧一次”并不适用于所有产品。粉彩论文摘要将彩料、彩绘和纹饰彩烧一起讨论，也强调了工艺与风格之间的联系。[^fencai]
