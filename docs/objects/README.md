# 器物分类

景德镇陶瓷器物可以同时从**用途、器型、时代、装饰工艺和生产体系**等维度分类。考古学研究通常需要把器型与胎釉、纹饰、制作痕迹和出土背景结合起来。[R01][R03][R16]

## 用途维度

- 日用器：碗、盘、杯、壶等
- 陈设器：瓶、尊、炉等
- 文房器：笔筒、笔洗等
- 礼仪与祭祀相关器物
- 人物造像及其他雕塑类器物

以上分类只是检索维度，同一器物可能同时具有多种属性。[R04][R03]

## 器型与时代

湖田窑考古报告按照不同历史阶段整理出土器物，可以观察器型、装饰和生产技术随时间的变化。[R01]

御窑厂考古则提供了元代后期至明清不同阶段的器物、瓷片、窑具和作坊遗迹，使器型研究能够与明确的考古地层联系起来。[R03]

## 研究一件器物的基本方法

1. 记录器型与尺寸。
2. 观察胎、釉、足部和制作痕迹。
3. 记录装饰位置、题材和技法。
4. 核对出土地点、传承来源或收藏记录。
5. 与考古出土器和专业图录比较。
6. 必要时结合科学检测。

单一特征通常不足以完成可靠断代或真伪判断。[R03][R16]
