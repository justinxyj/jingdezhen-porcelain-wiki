# 明清

## 概述

明清时期是景德镇陶瓷生产体系高度发展的阶段。御窑生产、民窑生产以及日益成熟的国内外市场共同塑造了这一时期复杂的陶瓷产业与文化面貌。

## 研究重点

- 御窑厂及相关生产制度
- 青花、五彩、斗彩、粉彩等装饰传统的发展
- 官窑与民窑之间的生产关系
- 陶瓷贸易、外销与跨文化交流
- 城市空间、窑炉技术与生产分工

## 重要说明

“官窑”和“民窑”并不是简单等同于“高档”和“普通”。实际历史中的生产、使用、流通与消费关系更加复杂，具体讨论应结合时代和制度背景。
