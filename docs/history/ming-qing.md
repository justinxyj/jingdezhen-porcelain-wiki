# 明清：御窑生产、民窑与彩瓷

明清景德镇瓷业需要同时从生产端与使用端理解：御窑遗址保存作坊、窑炉、工具和废弃物，宫廷与其他收藏保存被使用或流传下来的器物。两类资料相互补充，但没有完全相同的代表范围。

## 御器厂的年代与空间

北京大学考古文博学院介绍，2002—2004年发掘揭露御窑厂围墙、窑炉、辘轳坑和落选御用瓷片坑。2014年发掘位于遗址中部西侧，面积400平方米，清理作坊、灰坑、房址、道路、庭院等遗迹64处，地层从元代后期延续至清末民国。该文据元代和明初地层，将明御器厂始建年代判断为洪武末期。这个判断应明确归属于该考古研究，不能简单用一个未经解释的“洪武二年”替代。[^kilns]

御窑不是只有一座窑炉的地点，而是由制坯、加彩、装烧、选验及废弃物处理等环节组成的生产空间。不同阶段的布局变化，有助于讨论劳动分工与管理制度。

## 落选器物为什么重要

落选瓷片保存被淘汰的产品和制作痕迹。修复后的器物有助于观察形制和纹饰，但拼合结果仍须与原始地层、器物组合和修复记录一起阅读。完整宫廷传世品与窑址废弃物各有筛选过程，不应将任何一类当成当时全部产量的直接缩影。[^kilns]

## 官作与民窑

“官”与“民”首先涉及生产组织、供给对象和管理关系，不是单纯的质量等级。北大考古资料指出，晚明地层反映御器厂停烧前后生产机制变化与民窑继续生产的情况。因此，宫廷生产的变化并不意味着整座城市同时停止制瓷。[^kilns]

## 彩瓷与原料的发展

2014年发掘发现明中期釉上彩作坊与彩瓷半成品，为研究彩绘流程提供生产端证据。清代粉彩则应结合釉上彩料、彩绘技法和使用对象讨论。汪凌川博士论文摘要将粉彩形成放在康熙晚期、成熟放在雍正时期，并分别讨论官窑和民窑的风格演变；摘要中的分期是研究者的分析框架，并非所有器物可凭一个风格词直接断代。[^kilns][^fencai]
