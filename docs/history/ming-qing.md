# 明清

## 御窑体系

明清景德镇研究的核心遗址是珠山御窑厂。御窑厂是为宫廷用瓷服务的官办生产机构，其遗址考古可以同时观察生产制度、作坊布局、窑炉、窑具、产品和废弃物处理。[R03]

2002—2004年，北京大学考古文博学院与江西省文物考古研究所、景德镇市陶瓷考古研究所联合发掘御窑厂珠山北麓、南麓，发掘面积1578平方米，清理围墙、窑炉、辘轳坑和落选御用瓷器掩埋坑等遗迹。[R03]

2014年又开展主动性发掘，揭露了元代后期至清末民国时期的地层，并发现作坊、灰坑、房址、道路、庭院、辘轳坑等遗迹；同时发现明中期生产釉上彩瓷的作坊。[R03]

## 官窑与民窑

景德镇历史上的官作与民窑并非简单的“高档/低档”二分。官方文化生态保护规划把官窑和民窑都视为景德镇陶瓷文化景观的重要组成部分，并指出两者之间存在技术、人员和生产关系的交流。[R22]

因此，研究明清景德镇时，应同时观察御窑厂内部生产与城市范围内大量民窑、作坊及商贸网络。[R22]

## 青花与彩绘

明代早期青花研究显示，洪武、永乐、宣德等阶段在胎釉、青料、纹饰和工艺方面存在变化。御窑考古出土材料又把部分釉色和装饰工艺的出现时间向前推进，为器物研究提供了新的考古依据。[R03][R16]

景德镇瓷业志资料指出，元代中期以后青花成为重要的釉下彩绘体系，其基本工艺涉及含钴彩料、釉下绘画和还原焰烧成；明清时期又形成更丰富的彩绘体系。[R08]

## 清代工艺与生产

《景德镇陶录》和《浮梁县志》等清代文献直接记录了御窑厂、陶务、陶匠、色料和烧造制度，是研究清代景德镇生产组织的重要一手材料。[R04][R06]

《景德镇陶录》还把景德镇陶务、窑考、镇器及御窑厂作为独立篇章处理，说明清代景德镇已经形成较完整的行业知识体系。[R04]

## 外销

宋元以来的海外贸易在明清继续扩张。历史文献和考古研究显示，景德镇瓷器长期进入东亚、东南亚以及更远的海外市场；外销需求也与器型、纹饰和生产组织的变化存在关系。[R18]
