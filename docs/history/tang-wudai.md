# 唐五代

## 窑业发展的考古基础

景德镇早期瓷业的研究主要依赖窑址考古和出土器物。湖田窑考古报告把遗存划分为多个历史阶段，涵盖五代、北宋、南宋、元、明等时期，为研究景德镇民窑长期发展提供了连续材料。[R01]

景德镇陶瓷科技史研究综述指出，20世纪70年代湖田窑清理发掘是景德镇陶瓷研究史上第一次以较系统考古方法开展的大规模陶瓷考古工作，此后又有御窑厂等遗址的持续发掘。[R12]

## “昌南”与城市名称

地方志建置资料记载，景德镇在宋景德元年置镇，在此前的历史名称中包括东晋的“新平镇”和唐代的“昌南镇”。[R07]

这里需要把**城市建置史**和**窑业史**分开：一个地名什么时候出现，并不能自动证明某一种瓷器在该年才开始生产。[R07][R01]

## 研究重点

- 五代及宋初窑址的地层与器物
- 青白瓷形成前后的胎、釉和成型技术
- 窑炉、作坊、窑具与生产组织
- 景德镇与江西区域窑业之间的关系
