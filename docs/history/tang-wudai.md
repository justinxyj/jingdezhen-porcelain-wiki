# 唐五代：早期窑业与证据的边界

唐五代是理解景德镇早期窑业的起点，但“地方何时设镇”“何时开始烧瓷”和“何时出现某种产品”是三个不同问题。地名沿革来自建置文献；生产年代则需要窑址、地层和出土器物支持。不能把一个地名的出现直接当成瓷器创烧的年份。

## 早期生产如何被发现

肖红艳等人在2020年的原料研究中，引用乐平南窑调查材料，将景德镇地区的早期窑业追溯到中唐。国家非遗项目简介则以五代开始生产瓷器概括景德镇制瓷史。两种表述涉及的地域范围和材料不同，不能省略“地区”与具体窑场，合并成一个精确的全城创烧日期。[^materials][^heritage]

早期窑址研究的重要对象是窑炉、匣钵、垫具、原料和烧造废品。窑具与粘连、变形、过烧的瓷片能够证明生产活动；完整器物即使形制相似，也未必能独立证明生产地点。产品断代还要结合它在地层中的位置，而不是仅凭“古朴”或“胎厚”判断。

## 从早期瓷胎观察技术积累

2020年论文整理五代至清代瓷胎检测数据，认为五代至南宋的景德镇瓷器主要采用单一瓷石原料。这里的“一元”指配料方式，并不是说瓷石只有一种矿物。不同矿床的成分和加工方式仍会影响坯料性能。[^materials]

把早期瓷业写成后来青花与御窑的“准备阶段”，容易忽略当时自身的器用需求和技术选择。早期产品应首先放在本期的生产与消费背景中解释，再讨论它们与宋代窑业的联系。
