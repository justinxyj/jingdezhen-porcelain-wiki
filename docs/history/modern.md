# 近现代

## 晚清到民国：传统产业的现代转型

景德镇近代陶瓷史不仅是“传统手工业衰落史”，也包含企业组织、教育和技术改良等变化。景德镇陶瓷大学校史资料记载，1909年江西瓷业公司获准成立，并在其体系中筹设中国陶业学堂；这一过程反映出近代陶瓷业开始引入企业组织和职业教育机制。[R32]

## 1949—1966：生产制度与科技转型

相关科技史研究指出，1949—1966年景德镇陶瓷业经历了明显的制度和科技变化，传统陶瓷产业成为中国传统手工业向现代工业转型的一个研究案例。[R20]

地方行业志资料显示，1949年后景德镇建立陶瓷生产管理机构，1950年代逐步实行计划管理和公私合营；1958年陶瓷企业转为地方国营瓷厂体系。这些制度变迁应与当时全国经济制度背景一起理解。[R20]

## 工艺与现代技术

现代化并没有使所有传统工艺立即消失。以薄胎瓷为例，研究者根据传承人口述史，把改革开放以来的发展划分为1978—1986年恢复期、1987—1995年发展期、1996—2004年过渡期和2005年至今的创新期。[R21]

## 非遗保护

2006年，景德镇手工制瓷技艺列入第一批国家级非物质文化遗产代表性项目名录。国家级项目资料将其历史工艺概括为原料加工、成型、装饰、施釉、烧成等相互关联的技术体系，并记录其师徒传承和行业习俗。[R19]

## 世界遗产

2026年，“景德镇手工瓷业遗存”列入《世界遗产名录》。UNESCO 对其价值的描述强调10—19世纪手工制瓷业的连续性，以及原料开采、燃料、窑炉、生产组织和贸易等组成部分。[R23]
