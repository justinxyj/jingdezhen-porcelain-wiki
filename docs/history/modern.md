# 近现代

## 概述

进入近现代后，景德镇陶瓷业经历了生产制度、市场环境、社会组织和技术条件的持续变化。传统手工业与现代工业、艺术创作、教育和文化旅游等新形态逐渐交织。

## 研究重点

- 传统窑业在近代社会经济变化中的转型
- 新中国成立后的陶瓷生产与教育体系
- 景德镇陶瓷艺术与现代设计的发展
- 当代陶瓷产业、工作室经济与文化空间

## 当代延伸

现代景德镇不仅是生产陶瓷的城市，也是陶瓷艺术、设计、教育、展览、文创和青年创作的重要聚集地。具体产业数据与机构信息应使用对应年份的官方统计或机构资料。
