# 近现代：企业、教育与生产方式的转型

近现代景德镇陶瓷史不仅是器物风格变化，也涉及企业组织、学校教育、材料研究、机械化生产和手工技艺保护。传统与现代生产之间既有变化，也有延续，不能用“手工被机器完全取代”概括全部过程。

## 近代改良与中国陶业学堂

景德镇陶瓷大学校史资料记载，江西瓷业公司及中国陶业学堂的筹办与晚清陶业改良相联系。学校将“明白学理”和“精进技术”结合，设置试验窑、陶泥与制坯设施，并讨论机械制瓷和以煤窑替代柴窑的目标。学校早期地点和组织沿革须按校史核对，不能因其后来与景德镇教育相联系，便把所有早期设施都写成设在今天的景德镇校址。[^education]

校史还记述试烧遇到问题、改进烟道后取得进展的过程。这个案例说明新技术不是购买设备后就立即成功，还需要原料、窑炉、操作和人才之间的调整。

## 学理与经验的重新组织

传统经验通过师徒与生产协作传递，现代课程增加数学、理化、图案和实验等知识。两者服务于不同学习方式，也可以互相补充。把温度、原料和器物缺陷转化为可记录的实验问题，是理解近现代技术变化的一条线索。[^education]

## 现代生产与历史资料

国营企业、地方产业、工作室和艺术市场的变化，需要按具体年代和机构研究。产量、出口、就业与企业数量应注明年份与统计口径。某一瓷厂的改制经历不能直接代表整座城市，也不能用当代旅游宣传替代工业史资料。

## 技艺保护与持续生产

景德镇手工制瓷技艺于2006年列入第一批国家级非遗代表性项目，项目编号Ⅷ-7。非遗保护涉及分工、工具、工序及知识传递，而不只是保留几件代表性精品。[^heritage]

窑址和生产设施的保护与活态技艺保护互有关联，但属于不同对象。世界遗产、国家级非遗与文物保护单位的认定体系也不同，不能互相替代。

参阅[教育与研究](../contemporary/education.md)、[产业与社会](../contemporary/industry.md)和[遗产保护](../contemporary/heritage.md)。

## 从材料实验到陶瓷考古

郑乃章等2007年的研究史综述指出，近代景德镇已有以科学技术手段研究瓷器和生产的活动，早期陶瓷史研究则较多依赖文献与窑址踏查。二十世纪七十年代湖田窑清理发掘及后来御窑考古，使地层、遗迹和出土组合成为系统研究的重要材料。作者将“科技研究先于科学考古介入”概括为景德镇研究史的一项特点。[^science]

材料测试解释胎釉和烧成，考古解释年代与生产环境，机构史解释这些研究由谁组织。三者的结合，使传统制瓷经验逐渐进入可记录、比较与复核的知识体系。

## 薄胎瓷：从行业变化看工艺延续

况立、陈宁依据工艺调查及传承人熊国安口述史，把改革开放后的薄胎瓷发展划分为1978—1986年恢复期、1987—1995年发展期、1996—2004年过渡期，以及2005年起的创新期。该分期发表于2023年的研究摘要，体现作者对特定工艺的解释，不能直接替代整座城市的产业分期。[^eggshell]

口述史的价值在于补充手部经验、学习过程和生产协作等文字档案较少记录的内容。将口述与有年代的作品、企业资料和其他访谈对照，可以更具体地理解旧技艺怎样适应新的组织与市场。
