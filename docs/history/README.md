# 景德镇陶瓷史概览

景德镇陶瓷史不宜只用单一“起源年份”概括。不同历史时期在窑址、原料、技术、产品体系、生产组织和市场范围上均有变化，本页用于建立时间轴，并链接到各时期专题。

## 阅读原则

“景德镇陶瓷”既包括地方窑业史，也包括技术传播、生产组织、商品流通与城市发展。涉及具体年代、窑址归属和技术源流时，应优先引用博物馆、考古报告、学术专著或同行评议研究。
