# 景德镇陶瓷史概览

景德镇陶瓷史应同时观察**窑址、原料、技术、生产组织、城市建置、贸易与文化遗产**。现有考古与文献资料显示，景德镇并不是在某一年突然成为“瓷都”，而是在长期窑业发展、技术积累和市场扩张中逐步形成区域性制瓷中心。[R01][R07][R12]

## 一个重要的城市史问题

《景德镇市志》建置资料记载，景德镇在宋景德元年置镇，此前东晋称新平镇、唐称昌南镇；1949年就镇设市。[R07]

“景德镇为什么叫景德镇”属于需要文献辨析的问题。地方志中的建置记载、后世传说和现代解释不能混为一谈；Wiki 对名称来源只采用可以追溯到文献的表述。[R07]

## 阅读方法

景德镇陶瓷史中的“青白瓷”“青花”“御窑”“民窑”“二元配方”等概念都存在具体的时代和学术语境。Wiki 不使用“从古至今一直不变”的叙事，而是把技术、制度和产品放回相应年代讨论。
