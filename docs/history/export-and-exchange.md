# 外销与交流：景德镇瓷器怎样进入海外生活

景德镇的海外联系不仅表现为瓷器运往远方，也表现为海外用途进入器物的形制和装饰。研究这种联系，需要同时观察生产地、贸易参与者、使用方式与收藏史。V&A的青花专题以有明确编号的馆藏器说明这些变化，为跨地区比较提供了具体起点。[^va]

## 从海上贸易到不同市场

V&A概述，十六世纪大量青花瓷进入欧洲，先通过葡萄牙商人，随后有荷兰东印度公司及其他贸易者参与。十七世纪，中国与日本都有专门面向欧洲市场的陶瓷生产。贸易参与者的变化扩大了商品流通，但生产、运输、销售和使用仍是不同环节；确认一件器物的经营者或航线，需要比产地记录更具体的证据。[^va]

欧洲之外，日本及东南亚也是观察中国陶瓷流通的重要地区。V&A列出马尼拉出土的1450—1550年中国陶瓷，以及1621—1627年景德镇制造、面向日本市场的盘。出土地点揭示器物曾到达哪里，器形与纹样则可进一步讨论它怎样被选择和使用。[^va]

## 海外用途怎样改变器物

跨文化交流并不只是在器物上添加异国纹样。调味器、成组陈设瓷和餐饮用具对器体结构、尺寸和搭配方式都有要求，生产者需要把这些需求转化为适合制瓷的形制。

| V&A馆藏实例 | 年代与产地 | 可以观察的问题 |
| --- | --- | --- |
| 克拉克瓷盘，C.230-1926 | 1573—1620年，景德镇 | 中央主题与交替分区边饰怎样组织盘面 |
| 面向日本市场的盘，FE.6-1982 | 1621—1627年，景德镇 | 中国生产与日本使用需求的联系 |
| 油醋壶，C.91-1956 | 1680—1700年，景德镇 | 瓷器怎样借鉴可分装油醋的欧洲玻璃器形 |
| 盖罐，C.113-1963 | 1662—1722年，景德镇 | 器物怎样适应家具或壁炉架上的陈设，并结合不同装饰因素 |

以上年代、产地与编号均对应V&A专题中的具体对象，不作为同类器物的统一断代。油醋壶尤其显示，外销适应可以涉及实际功能；盖罐则将问题带入欧洲居室的观看和摆放方式。[^va]

## 青花传播并非单一的仿制关系

蓝白配色和某种纹样的相似，可以提示比较方向，却不足以证明两地采用相同胎料、釉料或烧成技术。V&A介绍的一件有田碗使用简化的“寿”字纹样，并将它联系到中国福建流行的青花装饰。这个实例说明，中国陶瓷对海外的影响有不同来源，不能全部归入景德镇。[^va]

景德镇向日本供应瓷器、日本本土生产吸收中国图案、日本瓷器再销往欧洲，是彼此相关但并不相同的过程。比较时把产地与流通方向写清楚，才能看到不同生产中心的主动选择。

## 十九世纪英国的青花收藏

十九世纪五六十年代，英国唯美主义圈子中的惠斯勒、罗塞蒂等艺术家和知识分子重视青花的色彩、材料与形式，青花收藏随后进入更广泛的中产阶级居室。用于陈列瓷器的橱柜和家具，把器物从饮食用具或贸易商品转化为室内审美的一部分。[^va]

航运商弗雷德里克·理查兹·雷兰委托设计专门陈列青花的房间。孔雀厅最初由托马斯·杰基尔设计，后来经惠斯勒重新装饰；装饰方案、瓷器陈列与收藏者之间的关系，说明陶瓷史也包括器物抵达目的地后的观看、评价和再解释。[^va]

## 从一件外销瓷继续追查

完整的对象研究可沿三个问题展开：它在哪里、何时制作；有哪些证据说明运输或订制关系；它在抵达之后如何使用、收藏或改装。今天收藏于海外博物馆，只能直接说明现今收藏地点，不能单独证明制作时的目标市场。

## 制瓷知识怎样越过海洋

器物、图像和文字以不同速度流通。法国国家图书馆专题记述，欧洲在长期输入中国瓷器之后，才于十八世纪初取得硬质瓷研制进展：迈森地区1708年前后的实验利用当地高岭土资源；殷弘绪则在1712年书信中详细介绍景德镇原料与专业分工。两者的时间顺序提示，欧洲制瓷不能被写成读到一封信后直接复制中国技术。[^bnf]

报告经书信集、杜赫德著述与百科编纂传播，生产图册也被制作、运往法国并进入收藏。1856年《景德镇陶录》的法译加入塞夫勒化学家Salvétat注释，使中国历史文献又与欧洲材料研究发生联系。瓷器交流史因此包含实物贸易，也包含观察、翻译、图像制作与实验。

## 纹章、样本与定制

Met外销瓷专题举出十六世纪葡萄牙王室纹章执壶、十八世纪纹章餐具和烛台等实例。欧洲需求可以通过器形样本或装饰图稿传给中国作坊；纹章从青花转向多色釉上彩，也与更准确表现图案的需求有关。专题对部分木质样本的使用采用推测性措辞，本文保留这一证据层级，不将所有外销器都视为有实物样本可查的私人订单。[^metexport]
